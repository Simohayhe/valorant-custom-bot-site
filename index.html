DISCORD BOT FOR VALORANT CUSTOMS

カスタムの準備は、
ボタンだけでいい。

参加者をボタンで集めて、ランクで戦力を揃えた2チームに分け、DiscordのVCへ自動で移動。チーム分けからマッチ終了まで、主催者はボタンを順番に押すだけです。

＋ サーバーに追加する 使い方を見る

招待するとすぐに /custom start が使えます。詳しい使い方はDiscordで /help

できること

カスタムで毎回やっている面倒を、botがまとめて引き受けます。

⚖️

ランクで戦力を揃える

分け方を全通り調べて、両チームの平均ランクが最も近くなるように分けます。2試合目以降は、同じチームメイトが続かない組み合わせを優先。

🔊

VCへ自動で移動

ボタンひとつで各チームのVCへ移動。休み・観戦の人は観戦VCへ。試合後はロビーへ戻します。VCが無ければ確認してから作成。

🏅

ランクはサーバーごとに保存

最高ランクを一度登録すれば、そのサーバーでは次からも使えます。パネルの名前の横にランクのアイコンが並びます。

👥

最大20人まで

10人を超えたら、主催者が今回休む人を選びます。「おまかせ」なら出場回数が少ない人から順に選ぶので、全員がほぼ同じ回数出場できます。疲れた人は自分で観戦に回ることもできます。

🤝

同じチーム指定

「この人たちは同じチーム」を主催者が指定できます。指定は主催者にだけ見えます。出場を固定する機能も。

🔇

ゴースト防止

試合中、チームVCに部外者が入ってきたら自動でミュート。試合が終わると自動で解除します。

🏆

勝敗の記録

オプションで勝敗を記録。勝率をチーム分けに少し反映し、/custom stats で成績を確認できます。

🏠

複数カスタムを同時に

オプションで、1つのサーバーで最大4つのカスタムを同時に進められます。部屋ごとにVCと主催者が独立。

試合の流れ

主催者にだけ見える「主催者メニュー」に、次に押すボタンだけが出ます。

チーム分け

参加者をランクで2チームに。気に入らなければ「組み直し」。

マップ抽選

前回と違うマップを抽選。「引き直し」もできます。

試合開始

全員をチームVCへ移動。休み・観戦の人は観戦VCへ。

マッチ終了

全員をロビーに戻す。同じチームでマップだけ変える「再戦」も。

始め方

3ステップ。設定は後からでも大丈夫です。

  1. 1. サーバーに追加
    上の「サーバーに追加する」から招待します(サーバー管理権限が必要)。必要な権限は招待画面で一緒に付与されます。
  2. 2. VCを決める(任意)
    /custom setup でロビー・チームA・チームB・観戦のVCを、既存から選ぶか新しく作ります。設定しなくても、最初の試合開始のときに、確認してから作成します。
  3. 3. カスタムを始める
    /custom start で募集パネルを出し、みんなに「参加」を押してもらいます。あとは主催者が「主催者メニュー」のボタンを順番に押すだけ。

コマンド

ほとんどの操作はボタンでできます。コマンドは補助的に使います。

コマンド説明
/custom start募集パネルを出す
/custom panelパネルを今のチャンネルに出し直す(流れたとき)
/custom end進行中のカスタムを終了(主催者・サーバー管理者)
/custom setupVCの設定と、ミュート・勝敗記録・複数カスタムのON/OFF
/custom host主催者を設定・交代(カスタムを始める前でも可)
/custom add / kick主催者が手動で参加者を出し入れ
/custom stats勝敗記録の成績(勝敗記録ONのとき)
/rank自分の最高ランクを登録・更新
/help使い方を表示(自分にだけ表示)

よくある質問

 

必要な権限は？
  • チャンネルを表示 / メッセージを送る / 埋め込みリンク / メッセージ履歴を読む … パネルの表示と更新
  • 接続 / メンバーを移動 … VCへの自動移動
  • チャンネルの管理 … チーム用VCの自動作成
  • メンバーをミュート … ゴースト防止のミュート

管理者権限は不要です。特権インテント(メッセージ内容・メンバー)も使いません。

参加者に通知が飛びまくらない？

botが送るメッセージはすべてサイレント(プッシュ通知・通知音なし)です。主催者向けの操作は主催者にだけ表示されます。

どんなデータを保存しますか？

DiscordのユーザーID、登録した最高ランク、カスタムの参加状況・出場回数、(勝敗記録ONのサーバーのみ)勝ち数と負け数、サーバーごとの設定(VC・主催者など)だけです。メッセージの内容やボイスは保存・記録しません。

いつでも動いていますか？

個人で運営しているため、メンテナンスなどで一時的に止まることがあります。止まっても参加者やランクなどの状態は保存されていて、復帰後にそのまま続きから使えます。

VALORANTの戦績と連携していますか？

していません。ランクは本人が登録した「最高ランク」を使います(主催者が変更することもできます)。
